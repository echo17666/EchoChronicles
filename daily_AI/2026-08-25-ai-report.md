### 📡 近期值得关注的前瞻动态

### 阿里云万相 Wan3.0 视频生成模型全面开放
**发布时间：** 2026年8月24日
**发布公司：** 阿里云（阿里巴巴）
**详细内容：** 阿里云万相 Wan3.0 视频生成模型于8月24日正式全面开放。该模型支持单次生成最长30秒视频，是前代 Wan2.7（15秒上限）的两倍，分辨率最高可达1080p。Wan3.0 首次支持 DOC、XLS、PPT、PDF、Markdown 等多种文档格式作为输入，在生成时长、多元创作、通用参考、真实世界还原四个维度进行了升级。8月24日至9月23日期间，部分平台提供API限时7折优惠。值得注意的是，该模型自8月初起已通过阿里云 Model Studio 和通义云平台进行公开测试，8月24日的发布是正式全面开放。
**来源：** TechNode、Reuters

### 智象未来 HiDream-O1-World 交互式世界模型
**发布时间：** 2026年8月17日（8月24日国际媒体发布）
**发布公司：** 智象未来（HiDream.ai）
**详细内容：** 智象未来正式发布 HiDream-O1-World，一款原生全模态交互式世界模型。该模型具备漫游、编辑、交互三大功能，支持文字、图像、交互式操控等多模态输入，搭载自研 UiT（Unified Transformer）架构。在第三方评测 WBench（由美团 LongCat 团队与复旦大学联合推出）中，HiDream-O1-World 在核心的 Navi 分榜以平均分80.9登顶，物理维度73.3分位列第一，一致性维度达88.0分。相关论文入选 ECCV 2026。
**来源：** 36氪、Media OutReach

### OpenAI GPT-5.6 Sol API 大幅降价
**发布时间：** 2026年8月24日
**发布公司：** OpenAI
**详细内容：** OpenAI 宣布 GPT-5.6 Sol API 价格下调超过20%，输入/输出短期促销价调整为每百万 token 4美元/20美元，促销期至少持续至2026年11月21日。GPT-5.6 系列包含 Sol（旗舰）、Terra 和 Luna 三个变体，分别针对不同性能和成本需求。此次降价被视为在激烈的价格竞争中对开发者的回应。
**来源：** Technology Org、Reuters

### Ox Alpha 匿名AI编程模型引发热议
**发布时间：** 2026年8月20日
**发布公司：** 匿名（疑似中国AI公司）
**详细内容：** 一款名为 Ox Alpha（亦称 0x Alpha）的匿名AI编程模型于8月20日悄然上线 OpenRouter 和开源终端代理工具 OpenCode。该模型宣称拥有1,048,576 token 上下文窗口、131,072 token 最大输出，以及每日100万亿 token 的 alleged 处理能力。模型支持文本、图像和视频输入，定位为推理模型，适用于长周期软件工程和持续代理工作。社区测试显示其在 DeepSWE 基准上表现与 GPT-5.6-sol 中档相当。开发者 unclecode 通过指纹工具 modelprint 发现该模型与 Z.ai（智谱AI）的 GLM-5.3 在六项基础设施探测中匹配，但 Z.ai 未确认此关联。
**来源：** SiliconANGLE、Cryptonomist
