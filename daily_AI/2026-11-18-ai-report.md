### OpenAI GPT-6.2 Astra & GPT-6.2 Sol
**发布时间：** 2026年11月17日
**发布公司：** OpenAI
**详细内容：** OpenAI发布GPT-6.2系列两款新模型。GPT-6.2 Astra定位前沿专业模型，在Agents' Last Exam基准测试中比GPT-6 Astra高出5.2分，成本不到三分之一；相比Claude Fable 5.2领先5.5分，成本仅5%。在科学工作基准Terminal-Bench-Science 0.1上，比GPT-6 Astra高9个百分点。API定价为每百万Token输入8美元、缓存输入0.4美元、输出40美元，比GPT-6 Astra低20%。GPT-6.2 Sol定位日常高效工作模型，在多项基准上接近或超越领先模型，同时保持GPT-6.1 Sol的API价格。两款模型上下文窗口均为105万Token，已向Plus/Pro/Enterprise/Edu用户开放。

### 微软七款MAI系列模型
**发布时间：** 2026年11月17日
**发布公司：** 微软（Microsoft AI）
**详细内容：** 微软在旧金山Ignite 2026大会上由AI负责人Mustafa Suleyman一次性发布七款自研MAI模型：
- **MAI Code 2**：编程模型，达到GPT-6.1 Sol 98%的编码质量，价格仅40%；对比Claude Opus 5.5达到96%性能，价格仅5%
- **MAI Code 2 Flash**：轻量编程模型，以GPT-6 Luna 65%的价格匹配其性能
- **MAI Cyber 2 Flash**：网络安全专用模型，在CyberGymE2E基准上匹配GPT-6 Astra质量，单次任务成本不到2%，100万Token上下文，定价0.1美元输入/0.5美元输出每百万Token
- **MAI Image 2.7**：图像生成与编辑模型，登顶Artificial Analysis图像编辑榜，以GPT Image 2.6 Sunburst五分之一的价格超越其性能
- **MAI Image 2.7 Flash**：图像模型轻量版本
- **MAI Realtime 1**：实时语音模型，超越GPT-Realtime 2.1，音频每分钟仅0.01美元起
- **Microsoft-Decision 1.1**：决策模型，比GPT-Sol 6.1快50倍、便宜79倍
- **Dragon Copilot Transcribe**：基于MAI Transcribe 2的多语言转录模型
**来源：** Microsoft AI / Axios / TestingCatalog

### OVHcloud Olala Mini
**发布时间：** 2026年11月17日
**发布公司：** OVHcloud
**详细内容：** 欧洲云服务商OVHcloud发布其首款大语言模型Olala Mini，标志着欧洲云厂商正式进入LLM开发领域。该模型采用70亿参数MoE架构，每次推理仅激活10亿参数，每层256个专家。在RTX A4500 GPU上可达160 Token/秒，纯CPU环境下50 Token/秒。支持3.2万Token上下文，以Apache 2.0协议开源，完整权重和基础模型已上架Hugging Face。模型采用Differential-TPA与Mamba-3混合注意力机制，在欧洲三台超算（Jupiter、MeluXina、Jean Zay）上训练完成。欧洲搜索引擎Qwant已将其部署用于闪答功能，响应速度提升20%，运营成本降低66%。
**来源：** emergent.sh / OVHcloud
