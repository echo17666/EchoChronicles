### GLM-5.3
**发布时间：** 2026年8月14日
**发布公司：** 智谱（Z.ai）
**详细内容：**
智谱正式发布新一代旗舰模型 GLM-5.3，采用 7430 亿参数 MoE 架构，与 GLM-5.2 共用同一基座模型，所有能力提升全部来自后训练阶段的极致 Scaling。

核心亮点：
- **编程能力最强开源模型**：在内部体感评测中较 GLM-5.2 提升 50%，在 Terminal Bench 3.0、Agents' Last Exam (CLI) 等公开基准测试中取得开源第一
- **长程任务突破**：Terminal-Bench 3.0 得分从 4.6 提升至 28.3；DeepSWE v1.1 从 46.2 提升至 66.9
- **涌现网络安全能力**：发现 1097 个高危/严重漏洞，涵盖 Linux 内核、WebKit、FreeBSD 等，最老的漏洞可追溯至 1981 年；在 CyberGym 白盒代码审查基准上得分 84.5%
- **高效输出**：在 Z.ai Code Bench 中，High 档位准确率达 31.4%，超过 Claude Opus 4.8 的 29.5%，且每项任务平均仅输出约 5 万 tokens（Opus 4.8 需约 12 万 tokens）
- **上下文与输出**：支持 1M Token 上下文和 128K Token 最大输出
- **开源计划**：模型权重将在发布两周后开放，目前先完成安全评估与加固
- **即时可用**：已上线智谱官方编程工具 ZCode、效率工具 AutoClaw，并向 GLM Coding Plan 全量用户开放
