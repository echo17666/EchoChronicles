### OpenAI Astra 模型因安全风险评估暂停部分研发
**时间：** 2026年8月7日声明（8月9日广泛报道）
**发布公司：** OpenAI
**详细内容：** OpenAI 发布声明称，新一代 AI 模型 "Astra" 的最新内部评估显示，该模型在"网络安全活动"方面可能达到有严重风险的级别。评估发现 Astra 具备在脱离人类干预的状态下，仅凭宏观指令便自主挖掘并利用系统漏洞、甚至策划并执行完整网络攻击的潜在技术能力。为防范人工智能系统失控风险，公司决定暂停涉及该模型的部分内部研发活动，并全面升级相关安全管控机制。Astra 此前被业界描述为可让多个 AI Agent 拉群协同工作的下一代模型家族。
**来源：** 新浪新闻 / 彭博社 / 美国之音

### Anthropic 将 Claude Code 自动模式设为默认
**时间：** 2026年8月9日
**发布公司：** Anthropic
**详细内容：** Anthropic 宣布自 8 月 14 日起，将 Claude Code 的 auto mode（自动模式）设为 Pro、Max 和 Team 账户的默认设置，取代此前每一步都需人工批准的手动模式。在自动模式下，Claude Code 可自主继续执行操作，除非动作被判定为"不可逆、破坏性或指向外部环境"。Anthropic 公布的研究数据显示，在 1,053 名付费测试者中，自动模式拦截了 89% 的有害操作，而人工审查仅拦截 13.6%，原因在于用户习惯了批准 97% 的权限提示。公司同时新增了提示注入筛查和可定制的硬性拒绝规则等安全功能。
**来源：** TechCrunch
